Allow local PDF access

Chrome keeps file:/// documents private until you enable this extension’s local-file switch.

  1. Right-click the Dark PDF Viewer toolbar icon.
  2. Choose Manage extension.
  3. Turn on Allow access to file URLs.
  4. Return here and click Retry local PDF.

“Choose PDF instead” works without changing Chrome’s file-access setting.
